# Java Fundamentals

This repository contains my Java learning journey and practice code covering core Java concepts, object-oriented programming, JVM internals, collections, multithreading, Java 8 features, and interview-oriented topics.

The goal of this repository is to strengthen Java fundamentals through hands-on coding and concept-based learning.

## Topics Covered

### 🔹 Object-Oriented Programming (OOPs)

* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Interfaces
* Constructors
* Method Overloading & Overriding

### 🔹 Java Memory Model & JVM

* Heap vs Stack Memory
* String Pool
* Garbage Collection
* Pass By Value
* Class Loading

### 🔹 Collections Framework

* ArrayList
* LinkedList
* HashMap
* HashSet
* Queue & PriorityQueue
* Stack

### 🔹 Exception Handling

* Try-Catch
* Throw & Throws
* Custom Exceptions
* Finally Block

### 🔹 Multithreading

* Thread Creation
* Runnable Interface
* Synchronization
* Deadlock Basics

### 🔹 Java 8 Features

* Lambda Expressions
* Streams API
* Functional Interfaces
* Optional Class
